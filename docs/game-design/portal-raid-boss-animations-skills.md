# 攻略傳送門｜十種 Boss 攻擊動畫與技能效果

對應關卡規格：`portal-raid-10-stages.md`  
用途：給動畫／特效／戰鬥程式對表用。  
組隊：`R = min(關卡, 5)` → 輔×R／坦×R／戰×R，**最多 15 人**；點名數等隨 R 增加，Boss 本體動作不因人數改版型。  
數值：採削弱後個人能力（見主規格 §1.3、§1.4）；動畫表現不變，僅結算數值變弱。

圖例：
- **動畫**：角色動作與鏡頭表現
- **特效**：畫面 VFX／UI 提示
- **技能效果**：數值與狀態結果（以主規格削弱後數值為準）
- **讀條／預兆**：玩家可反應的警告時間
- **多人**：點名／圖騰等目標數隨 R 放大（滿編最多 5 點名、2 組齊拍）
